# PoeticAlps 项目作品集

一个自包含的静态导航页：把 GitHub 上所有项目按「在线体验 / 实用工具 / 私有仓库」分类展示，每个项目带一句话简介、技术标签和入口链接。

## 为什么有这个仓库

- 原 `my-repository` 与 `Ricardo`（合浦珠还失物招领平台）内容完全重复，前端已由 Ricardo 仓库统一维护；
- 本仓库改为承担"一个链接看完所有项目"的职责。

## 使用

- 双击 `index.html` 即可本地打开（无任何外部依赖，离线可用）；
- 若仓库转为公开并启用 GitHub Pages，可直接通过 `https://poeticalps.github.io/my-repository/` 访问。

## 维护

新增项目时在 `index.html` 对应分区复制一个 `.card` 块，改名称、简介、标签和链接即可。
